Cloud FAQs

What happens if a local plant loses internet?

Operations continue normally at the plant. The edge software queues all transactions and CCTV images locally. Once the connection is restored, it pushes the backlog to the cloud automatically.

Can I view CCTV snapshots in the cloud?

Yes, all compressed snapshots are synced to the cloud object storage, allowing you to visually verify any weighment from your phone.
