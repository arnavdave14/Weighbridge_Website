Software FAQs

Can I install it on multiple computers?

Yes, we support LAN networking. You can install the server on one PC and access the software from multiple client PCs across your local network.

Does it require internet?

No, the core desktop software works 100% offline. Internet is only required if you purchase the Cloud Dashboard or SMS/Email add-ons.
