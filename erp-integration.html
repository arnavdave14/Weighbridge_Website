Integration FAQs

Do we need to write ABAP code for SAP integration?

Your SAP team will need to expose standard RFCs or OData services for PO validation and GRN posting. Our middleware handles the consumption of these services. We provide comprehensive documentation to guide your SAP team.

What happens if the ERP server goes down during weighment?

The system can be configured in "Offline mode". It will generate a local ticket to keep trucks moving, and automatically queue the transaction to push to the ERP once the connection is restored.

Is the API documentation available?

Yes, we provide full Swagger documentation for our REST APIs, allowing your internal IT team or custom ERP provider to build seamless two-way integrations quickly.
